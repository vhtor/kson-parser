## KSON Parser

A simple JSON parser written in Kotlin.

### Features

- **JSON Parsing**: Parse JSON strings into Kotlin objects
- **JSON Generation**: Convert Kotlin objects back to JSON format
- **Type Safety**: Leverages Kotlin's type system for safe JSON handling
- **Lightweight**: Minimal dependencies with clean, readable code
- **Educational**: Written with learning purposes in mind, showcasing Kotlin language features

### Supported JSON Types

- Objects (`{}`)
- Arrays (`[]`)
- Strings
- Numbers (Integer and Double)
- Booleans
- Null values
